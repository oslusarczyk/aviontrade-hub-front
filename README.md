# AvionTrade Hub

> **⚠️ Work in Progress**  
> This project is currently under active development. Features and APIs may change.

## Overview

AvionTrade Hub is a web application designed to help you manage your FC26 Web App trading. 

## What is AvionTrade Hub?

AvionTrade Hub is a comprehensive trading management platform for FC26 Web App. It helps you:

- **Track your sales** - Monitor all your card sales with detailed profit/loss analytics
- **Manage your tradepile** - Keep track of your current tradepile
- **Automate data sync** - Sync your trading data from the web app using Chrome extension

## Technology Stack

- **TanStack Start** - Full-stack React framework
- **Convex** - Real-time database
- **Clerk** - Authentication

## Chrome Extension Required

This web application is designed to work **alongside a Chrome extension** that allows you to sync your data from the FC26 Web App.

### Getting the Chrome Extension

To use AvionTrade Hub, you'll need to install the Chrome extension:
